## Ako to funguje
1. Donesieš zbraň kováčovi a vyberieš si **tag** podľa typu zbrane.
2. Každý upgrade je **nákup** u kováča medzi výpravami, **nie downtime akcia**. Kúpiš toľko upgradov, koľko zaplatíš.
3. Upgrade pridá nový tag alebo zlepší existujúci o 1 stupeň. Zbraň môže mať viac rôznych tagov, ten istý tag však nie dvakrát (môžeš ho len zlepšiť).
4. Každý ďalší upgrade tej istej zbrane je **drahší**. Najviac **3 upgrady** na zbraň.

| Upgrade | Cena |
| --- | --- |
| 1. upgrade | 50 gp |
| 2. upgrade | 100 gp |
| 3. upgrade (strop) | 200 gp |
| Postriebrenie | 50 gp |

- Postriebrená zbraň zraňuje nadprirodzené bytosti normálne. Postriebrenie je tiež len nákup a nepočíta sa do limitu 3 upgradov.
- Tag pridaný kováčom **funguje hneď**.
- **Pár zbraní** (napr. dve dýky) sa ráta ako **1 zbraň**: upgrade dostanú oba kusy a platí sa raz.
- Magické zbrane a relikvie sa u kováča vylepšovať nedajú.

## Aký tag sa dá pridať

| Typ zbrane | Možné tagy |
| --- | --- |
| **Piercing** (bodné) | Bleed, Counter, Push |
| **Bludgeoning** (drvivé) | Shock, Heavy |
| **Slashing** (sečné) | Sweep, Quick, Heavy, Brutal, Bleed |

## Hodnota X

| | Nový tag začína na | Každé zlepšenie |
| --- | --- | --- |
| Sweep, Push, Shock, Bleed, Brutal | max kocky −1 (d6 → 5 · d8 → 7 · d10 → 9) | X −1 |
| Heavy, Counter, Quick | 1 | X +1 |

> [!example] Príklad: obyčajná dýka
> Dýka, Piercing (bodná) d6, Fast, bez tagu.
> - **1. upgrade:** Bleed 5 · 50 gp
> - **2. upgrade:** Bleed 4 · 100 gp
> - **3. upgrade:** Counter 1 *alebo* Bleed 3 · 200 gp

## Tagy

| Tag | Efekt |
| --- | --- |
| **Heavy X** (ťažká) | Ignoruj X brnenia, ale hody zranenia X a menej úplne minú. |
| **Sweep X** (rozmach) | Pri hode X+ dostaneš 1 bonusový útok na iný cieľ v dosahu (nereťazí sa). |
| **Push X** (odhodenie) | Pri hode X+ cieľa odtlačíš z Close (tesne pri tebe) na Nearby (neďaleko). |
| **Counter X** (protiúder) | Hody zranenia X a menej proti tebe sa odrazia späť na útočníka. |
| **Brutal X** (brutálna) | Kritické zranenie z hodu X+ je okamžité zabitie a nepriateľ si hádže Morale Save. |
| **Shock X** (omráčenie) | Pri hode X+ cieľ automaticky neuspeje v ďalšom DEX Save (1 kolo). |
| **Bleed X** (krvácanie) | Pri hode X+ cieľ dostane na začiatku svojho ťahu 1d4 STR zranenia (nespúšťa save proti kritickému zraneniu). |
| **Quick X** (rýchla) | Pri DEX save na to, či konáš pred nepriateľmi, máš DEX o X vyšší. |

## Typy zranenia

| Typ | Efekt |
| --- | --- |
| **Piercing** (bodné) | Pri maxime na kocke zranenia útok ignoruje celé brnenie (len s bežnou kockou zbrane). |
| **Bludgeoning** (drvivé) | Vždy ignoruje 1 brnenie. |
| **Slashing** (sečné) | +1 zranenie proti cieľom bez brnenia. |

Efekt typu zranenia sa odomkne:
- **sám:** 5 smrteľných úderov (killing blows) v smrteľnom boji so zbraňou daného typu, alebo
- **výcvikom** v [[dojo-zelezna-past|Doji Železná päsť]]: 1 downtime akcia a 50 gp za každý typ.

## Príklady zbraní
d6 = Fast · d8 = Balanced · d10 = Slow
